# 临时数据治理

M2-05 首阶段只提供 `cleanup` 只读计划。它帮助区分“看起来像项目残留”和“已经具备安全清理条件的项目对象”，但当前版本没有删除实现。

## 使用

```powershell
# 默认就是 dry-run
& "$SKILL_DIR\scripts\win.ps1" cleanup
& "$SKILL_DIR\scripts\win.ps1" cleanup --summary
& "$SKILL_DIR\scripts\win.ps1" cleanup --dry-run --json --summary
```

`--apply` 尚未开放，传入时会在扫描前退出 2；`--force`、`--dry`、未知选项和位置参数也会失败关闭。命令在桌面 helper 加载前分发，不编译 C#、不启动/停止进程、不接触窗口。

## 扫描范围

生产模式的根固定为系统临时目录。扫描只考虑它的直接子目录，且目录名必须完整匹配 `win-use-master-*` 的受限字符规则；不会扫描工作区、用户文档、LocalAppData 其它目录、相对路径、通配符展开结果或嵌套任意根。

只有目录不够。每个候选必须恰好包含一个 `manifest.json` 或 `.win-use-master-manifest.json`，schema 为 `win-use-master/temp-artifact-v1`：

```json
{
  "schema": "win-use-master/temp-artifact-v1",
  "artifactId": "win-use-master-example-0123",
  "createdAt": "2026-09-15T08:00:00Z",
  "expiresAt": "2026-09-16T08:00:00Z",
  "owner": {
    "pid": 1234,
    "startTimeUtc": "2026-09-15T07:59:50Z"
  }
}
```

`artifactId` 必须与目录叶名逐字相同。时间必须可解析、创建时间不能在未来、owner 启动不能晚于创建、生命周期不能超过 30 天。manifest 大于 64 KiB、两个 manifest、未知 schema、缺字段或伪造长生命周期都拒绝。额外字段不会进入报告。

## eligible 判据

一个候选只有同时满足以下条件才标记为 `eligible`：

- 位于准确的系统临时根直接下一层，名称属于项目命名空间；
- 候选、manifest 和内部树没有 reparse point；
- manifest 完整有效且 `expiresAt` 已到；
- 原 owner 已停止，或 PID 已被另一个启动时间不同的进程复用；
- owner 状态可确定，目录树可枚举且不超过 10,000 项。

当前 PID 仍对应 manifest 的相同启动时间时是 `active-owner`；读取启动时间失败是 `owner-unknown`。两者都拒绝。目录内出现 reparse point、访问失败或项目数超限也拒绝，避免将未来删除范围引向目录外或在异常大目录上失控。

`eligible` 只表示 dry-run 判据满足，不代表本版本会删，也不构成用户授权。正式开放删除前还需要二次扫描、防 TOCTOU 身份绑定、精确目标确认、逐项结果、部分失败语义和额外审查。

## 输出与隐私

JSON schema 是 `win-use-master/cleanup-plan-v1`。full 模式列候选叶名、决策、拒绝原因、创建/到期时间、owner 状态以及元数据大小；不输出根或候选绝对路径，不读取 payload 内容，也不复制 manifest 未知字段。summary 的 `items` 固定为空，只保留计数与策略。

每份报告都明确：

- `mode=dry-run`、`applyAvailable=false`；
- `sideEffects.filesWritten/filesDeleted/directoriesDeleted/processesStopped` 全为 0；
- `scope.rootPathIncluded=false`；
- `privacy.absolutePathsIncluded=false`。

报告状态 `empty` 表示没有命名空间候选，`ready` 表示至少一项满足 dry-run 判据，`review` 表示有候选但全部被拒绝。命令成功完成扫描时退出 0；边界无法验证或请求 apply 时退出 2。

## 契约测试

`tests/cleanup-contract.ps1` 在系统临时目录下创建唯一隔离扫描根，覆盖：有效过期项、活跃 owner、未过期、缺 manifest、错 schema、artifact ID 错配和非项目目录。测试对整个 fixture 的文件相对名、长度、时间戳和 SHA-256 建立前后指纹，确认 full/summary/default dry-run、`--apply` 拒绝和非法根拒绝均零修改；finally 只删除本次测试自己创建且再次验证过边界的 fixture。
