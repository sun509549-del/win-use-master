# 安装、升级、卸载与本地数据清理

本文区分两件事：OpenAI 的 [Build skills](https://learn.chatgpt.com/docs/build-skills) 文档说明 Skill 是含 `SKILL.md`、可选 scripts/references 的目录；本项目 README 使用的 `npx skills` 安装命令来自第三方开源 [vercel-labs/skills CLI](https://github.com/vercel-labs/skills)，不是 OpenAI 产品内置命令。执行前可在该 CLI 文档核对当前参数。

## 1. 安装形态

### skills CLI 管理

```powershell
npx skills add sun509549-del/win-use-master -g
```

CLI 会让用户选择目标 agent；Codex 的全局目录通常显示为用户目录下的 `.codex\skills\`，项目级目录显示为 `.agents\skills\`。以 CLI 实际输出为准，不要假设当前仓库目录就是安装副本，也不要手工删除不确定的 symlink 目标。

### Git clone 或手动目录

若直接 clone 或复制目录，先记住精确安装路径，并显式构建：

```powershell
$SKILL_DIR = 'C:\path\to\win-use-master'
pwsh -NoProfile -File "$SKILL_DIR\scripts\build.ps1"
pwsh -NoProfile -File "$SKILL_DIR\scripts\win.ps1" doctor --summary
```

`scripts\HuWin.dll` 是可再生生成物，不应从不可信来源复制。不要为运行本项目全局降低 Execution Policy、关闭 Defender/SmartScreen 或解除整棵下载目录的阻止标记。

## 2. 升级

由 skills CLI 全局安装时，按 skill 名升级：

```powershell
npx skills update -g win-use-master
```

Git clone 使用者先确认工作区没有自己的未提交变更，再执行快进更新和回归：

```powershell
git -C "$SKILL_DIR" status --short
git -C "$SKILL_DIR" pull --ff-only
pwsh -NoProfile -File "$SKILL_DIR\scripts\build.ps1"
pwsh -NoProfile -File "$SKILL_DIR\tests\run-tests.ps1" -Tier Contract
```

若 `status` 非空，不要覆盖或 reset 用户改动；先备份、提交到自己的分支，或改用一个新的干净目录。升级不会自动证明 Desktop/Coordinate 和真实 app 档案仍兼容；发布级使用仍需按 [`版本与发布.md`](references/版本与发布.md) 复验。需要退回旧版时按 [`回滚与恢复.md`](references/回滚与恢复.md) 新建精确目录，不覆盖当前安装。

## 3. 卸载 Skill

skills CLI 的全局安装可用其精确删除命令：

```powershell
npx skills remove --global win-use-master
```

若 CLI 显示多个 agent/副本，先使用交互模式 `npx skills remove` 核对范围；不要使用 `--all` 清空其它 Skill。Git clone 或手动复制的目录不受 CLI 管理，应先确认它确实是安装副本、没有未提交代码或用户证据，再通过文件管理器移除该精确目录。不要对 `$HOME`、`.codex`、`.agents`、工作区根或模糊匹配路径做递归删除。

卸载 Skill 不会自动删除本地缓存、CDP session、用户选择的 evidence 目录或源码 clone；它也不会关闭用户的目标应用。

## 4. 本地数据清单

| 数据 | 默认位置/来源 | 敏感性 | 安全处理 |
|---|---|---|---|
| 建议性能力缓存 | `%LOCALAPPDATA%\win-use-master\capability-cache-v1.json` | 低敏感产品/版本/框架观察，不含正文和授权 | 使用 `cache clear --all` 精确清除 |
| CDP 写 session | `%LOCALAPPDATA%\win-use-master\sessions\cdp-<port>.json` | 含端口、PID、exe 路径、target 身份与期限 | 关闭授权实例后逐文件核对并清除；不要递归删整个 LocalAppData |
| 版本检查日期 | 安装目录下 `.last-update-check` | 仅本地检查日期 | 随精确安装目录移除；无需单独清理 |
| C# helper | 安装目录下 `scripts\HuWin.dll` | 可再生二进制 | 随精确安装目录移除或下次构建覆盖 |
| 截图/map/receipt | 用户传给命令的 evidence 路径 | 可能含窗口标题、正文、账号、路径和像素 | 用户逐项复核后处理；项目不会猜测并批量删除 |
| 测试临时对象 | 系统临时目录下受限的 `win-use-master-*` 命名空间 | 可能含合成或真实证据 | 先运行 cleanup dry-run；生产 `--apply` 尚未开放 |

查看并精确清除建议缓存：

```powershell
& "$SKILL_DIR\scripts\win.ps1" cache show --json --summary
& "$SKILL_DIR\scripts\win.ps1" cache clear --all
```

只读列出 CDP session，不输出文件内容：

```powershell
$sessionDir = Join-Path $env:LOCALAPPDATA 'win-use-master\sessions'
Get-ChildItem -LiteralPath $sessionDir -File -Filter 'cdp-*.json' -ErrorAction SilentlyContinue |
    Select-Object Name, Length, LastWriteTimeUtc
```

session 当前没有批量清理命令。只有在目标 app/调试实例已关闭、文件名端口与本次授权一致且用户明确要清除时，才对单个已核对文件使用 `Remove-Item -LiteralPath <exact-session-file>`；不要使用通配符或 `-Recurse`。

临时对象只做安全预演：

```powershell
& "$SKILL_DIR\scripts\win.ps1" cleanup --dry-run --json --summary
```

退出码 2 表示安全拒绝或状态未知，不代表已经清理成功。当前版本的 `cleanup --apply` 固定拒绝；不要用脚本输出拼接删除命令。

## 5. 升级/卸载后的检查

- `npx skills` 输出的目标 agent 和范围符合预期；
- 旧 Skill 不再被 agent 发现，或升级后 `doctor --summary` 正常；
- 没有删除源码仓库、其它 Skill、用户 evidence 或所有权不明的临时目录；
- 没有遗留本项目启动且仍由用户授权运行的 CDP 调试实例；
- 任何清理失败都保留原对象并报告，不扩大路径范围重试。
